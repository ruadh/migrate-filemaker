## Application Structure

### Authentication Scheme

**APEX Authentication** with custom authorization schemes:

| Role | APEX Authorization Scheme | Privileges |
|---|---|---|
| **ADMIN** | `IS_ADMIN` | All pages, user management, system settings |
| **STAFF** | `IS_STAFF_OR_ADMIN` | All data pages, create/edit/delete records |
| **VIEWER** | `IS_VIEWER_OR_ABOVE` | Read-only access to all data |
| **OFA_ADMIN** | `IS_OFA_ADMIN` | Special administrative functions for OFA |

## Business Logic & Processes

### APEX Processes

#### After Insert/Update: Memorial Minute
- Validate required fields based on status
- Auto-create initial milestone records
- Send email notifications (if configured)

#### Before Insert/Update: Committee Member
- Validate only one Chair per memorial minute
- Check email format
- Ensure required contact information

#### On Status Change: Memorial Minute
- Update milestone tracking
- Trigger notification workflows
- Validate status transition rules

### APEX Validations

#### Memorial Minutes
- Date of Death cannot be in future
- HUID format validation (if standard exists)
- Required fields based on status

#### Committee Members  
- Email format validation
- Only one Chair allowed per memorial minute
- Academic title format consistency

### APEX Dynamic Actions

#### Status Change Reactions
- Show/hide milestone sections based on status
- Update progress indicators
- Enable/disable form regions

#### Committee Management
- Auto-populate email templates based on role

## Security Implementation

### APEX Authorization Schemes

```sql
-- IS_ADMIN
APEX_UTIL.GET_USER_ROLES(p_username => :APP_USER) LIKE '%ADMIN%'

-- IS_STAFF_OR_ADMIN  
APEX_UTIL.GET_USER_ROLES(p_username => :APP_USER) LIKE '%STAFF%' 
OR APEX_UTIL.GET_USER_ROLES(p_username => :APP_USER) LIKE '%ADMIN%'

-- IS_VIEWER_OR_ABOVE
APEX_UTIL.GET_USER_ROLES(p_username => :APP_USER) IS NOT NULL

-- IS_OFA_ADMIN
APEX_UTIL.GET_USER_ROLES(p_username => :APP_USER) LIKE '%OFA_ADMIN%'
```

### Page-Level Security
- Authorization schemes on all pages
- Item-level security for sensitive fields
- Region-level security for admin functions
- Button-level security for actions

### Data Security
- No row-level security required (matches FileMaker model)
- Audit columns track all changes
- APEX session state management
- Secure file access controls
