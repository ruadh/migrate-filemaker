# UI Specification

> Generated by `migrate-filemaker` Phase 4 — Plan

## Design Direction

### Target Style
**Clean & minimal modern SaaS look** with generous whitespace, simple navigation, and focus on usability. Professional appearance appropriate for Harvard Medical School academic administration.

### Current FM App Observations
**Analyzed 15 screenshots of current FileMaker application**

| Screenshot | Observations | Keep | Change |
|---|---|---|---|
| **Administration Detail** | Clean tabbed interface with well-organized fields in logical sections. Harvard crimson header bar. Status clearly displayed. | Tabbed organization, field grouping, status visibility | Modernize styling, improve field spacing, enhance visual hierarchy |
| **Committee Membership Tab** | Clean portal table with member details, roles clearly displayed. Filter functionality present. | Table format, role indicators, filtering | Add inline editing, improve column sizing, better action buttons |
| **Committee Milestones Tab** | Unique dual layout: checkbox milestones on left, detailed timeline on right. Very functional. | Dual-pane concept, milestone tracking approach | Modernize with progress indicators, better date handling, visual timeline |
| **Correspondence Tab** | Simple portal for communication tracking with document attachments. | Document attachment approach, simple table | Add email integration, improve file management, better correspondence threading |
| **Reference Documents Tab** | Basic document library with title and file attachment capabilities. | Document organization concept | Enhanced file preview, better categorization, improved search |
| **Status List Report** | Excellent comprehensive list with name, death date, chair, status, and recent activity. Color coding for status. | Status color coding, comprehensive columns, recent activity tracking | Improve visual design, add filtering/search, better responsive layout |
| **Committee Member Detail** | Comprehensive member profile with contact details, institutional affiliation, full address information. | Detailed member profiles, institutional tracking | Modernize form layout, improve contact management, add communication history |

## Navigation Structure

### Primary Navigation (APEX Top-Level Navigation)

```
┌─ Memorial Minutes System ────────────────────────────────────────────┐
│  [Dashboard] [Memorial Minutes] [Committees] [Documents] [Admin]      │
└─────────────────────────────────────────────────────────────────────┘

└─ Memorial Minutes ─────────┐
   ├─ All Memorial Minutes    │ (List view)
   ├─ Status Overview        │ (Dashboard)
   └─ Add New Memorial       │ (Form)

└─ Committee Management ─────┐
   ├─ Committee Members      │ (List view)
   ├─ Correspondence         │ (List view)
   └─ Progress Tracking      │ (Dashboard)

└─ Documents & Files ────────┐
   ├─ Reference Documents    │ (Library view)
   ├─ Photos & Images        │ (Gallery view)
   └─ Email Templates        │ (List view)

└─ Administration ───────────┐ (Admin only)
   ├─ User Management        │
   ├─ Lookup Tables          │
   └─ System Reports         │
```

### Navigation Implementation
- **APEX Navigation Menu** with hierarchical structure
- **Breadcrumb Navigation** for deep pages  
- **Harvard crimson header bar** to maintain brand consistency
- **Status indicators** prominently displayed (matching current FM approach)
- **Search** in top navigation bar for global search across all data

### Navigation Notes
- **Preserve tabbed interface pattern** - Users are comfortable with the Administration/Committee Membership/Milestones/Correspondence/Reference Documents tab structure
- Current FM uses script-based navigation - APEX provides standard web navigation with browser history
- **Maintain the dual-pane milestone view** - this is a unique and effective pattern users rely on
- Related record access via APEX interactive grids instead of FM portals but keeping similar visual organization

### Key Component Details

#### Committee Members Interactive Grid
- **Source:** `v_committee_members_with_names` view
- **Columns:** Full Name, Role, Status, Academic Title, Email, Actions
- **Editable:** All fields except computed name
- **Features:** Inline editing, role-based validation, email format checking
- **Actions:** Add member, delete member, send correspondence

#### Milestones Interactive Grid (Dual-Pane Layout)
- **Source:** `milestones` table  
- **Layout:** **Preserve FM's dual-pane approach** - milestone checkboxes on left, detailed timeline on right
- **Left Pane:** Checkbox grid for milestone completion status (Guidelines Sent, 3-Month Status, 6-Month Status, etc.)
- **Right Pane:** Detailed timeline with dates, notes, and activity history
- **Features:** Interactive checkboxes update timeline, date picker, rich text notes
- **Display:** Visual progress indicators showing completion percentage

#### Reference Documents Interactive Grid
- **Source:** `reference_documents` table  
- **Columns:** Title, Date Received, File, Comments, Actions
- **Features:** File upload/download, document preview, search
- **File Types:** PDF, Word, Excel, images (with size limits)

## Responsive Requirements

### Target Devices

| Device | Required | Priority | Notes |
|---|---|---|---|
| **Desktop (1280px+)** | Yes | Primary | Full layout, all features, optimized for office use |
| **Tablet (768–1279px)** | No | Not Required | User specified desktop browser only |
| **Mobile (< 768px)** | No | Not Required | Desktop-focused application |

### Responsive Strategy
**Desktop-first design** with minimal responsive considerations since users specified desktop browser access only. APEX Universal Theme provides basic responsive features that will ensure reasonable tablet viewing if needed, but optimization focus is on desktop experience.

### Desktop-Specific Optimizations
- **Large form layouts** with side-by-side field arrangements
- **Multiple column displays** for interactive grids
- **Hover states** for interactive elements
- **Keyboard shortcuts** for power users
- **Multiple browser tabs** support for concurrent work
- **Large file upload areas** for document management
- **Detailed tooltips** and help text
- **Expanded filter panels** for complex searches
